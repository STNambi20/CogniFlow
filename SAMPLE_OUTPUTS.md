# Sample outputs

The app produces live, source-linked outputs because search results and web pages change. Do not use fabricated sources as examples. Connect the API key, capture two or three real outputs during the demo using the three example queries in the UI, and paste each response into this file (or save a browser screenshot).

## Output shape

Each result includes:

- **Question** and **short answer**
- **Key findings**, each linked to one or more source IDs
- **Sources used**, including source URL, relevance score, and whether the page or snippet was used
- **Confidence** and the reason for the estimate
- **Assumptions**, **limitations**, and **suggested next steps**
- **Agent run trace**, showing planning, search, extraction/filtering, and synthesis mode

## Capture checklist

1. Run the vector-database comparison query with normal network access.
2. Save the result and confirm that each finding's source link opens.
3. Run the Indian HR-tech query and save the result.
4. Run one query with search blocked/unavailable to show error handling and the structured no-source response.
5. Add the exact query, date, synthesis mode, and output below. Keep the citations attached.
